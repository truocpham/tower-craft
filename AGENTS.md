## Kiln

This repo is built with Kiln: the `kiln` skill and CLI (`kiln --help`).

- "grill", "intake", "run", "loop", "status" and "retro" mean Kiln's: use the `kiln` skill, not another grilling or planning skill.
- Never start intake or the loop on your own. The owner opens a session to add requirements, to run the loop, or both: work out which from what they say, and ask while they are here if it is unclear.
- A new requirement, idea or bug goes through Kiln intake, which grills the owner and files tickets.
- Commits, PR bodies and tickets describe the change, never Kiln or Claude. In replies, name Kiln only for a Kiln command, the loop, or when the owner asks about it.
- Never mention cost, spend or dollars in replies or reports, and never pause or ask because of cost. Spend is logged for analysis only.
